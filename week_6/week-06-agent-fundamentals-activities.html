    Corte 2 · Week 6 of 16

    Lab & Activities

    Quiz, live coding with your first ADK and LangGraph agents, a trace-by-hand workshop, an individual tool-building lab, peer review, and picking your Corte 2 project problem.

    How this session runs

    2 hours of theory (content page) + 4 hours of hands-on lab (this page). Today you run your first real tool-using agents — one built with Google ADK, one with LangGraph — and start shaping your Corte 2 project idea.

    Activity 1 · Warm-up Concept Quiz

    10 minIndividualFormative

    1. In the Perception-Reasoning-Action loop, what turns an "Action" (a tool result) back into new input for the model?

    Correct answer: B. The observation becomes the next perception step, closing the loop.

    2. Who actually executes the Python function when an LLM "calls a tool"?

    Correct answer: C. The model only ever emits a request; your code is responsible for running it and returning the result.

    3. Your agent's tool has the docstring "handles topic stuff". It keeps getting ignored or misused. Why?

    Correct answer: A. Treat tool descriptions as the API documentation the model relies on.

    4. A task has a clear, predictable sequence of steps known in advance. Which pattern minimizes LLM reasoning calls?

    Correct answer: B. Plan-and-Execute pays for one planning call, then runs steps more cheaply.

    Activity 2 · Instructor-Led Live Coding

    40 minWhole group

    Follow along with the manual ReAct loop from the content page first — run it, then intentionally break the tool (rename it without updating the call site) to see the model receive an error observation and self-correct. Then switch to the runnable apps in agents/week-06-agent-fundamentals/:

    1. adk/campus_helper_agent/ — run with adk web agents/week-06-agent-fundamentals/adk, and open the trace panel to see the same Thought/Action/Observation loop, now automatic.
    2. langgraph/app.py — the same two tools wired into langgraph.prebuilt.create_react_agent. Run with python app.py.

    Activity 3 · Group Workshop: Trace a ReAct Run by Hand

    35 minGroups of 3–4

    Scenario: a user asks the campus helper agent, "How many total study hours should I budget for weeks 6 through 8, and which one is hardest?" Your group has access to get_course_topic(week) and estimate_study_hours(topic, difficulty) (difficulty is not given — the agent must guess a reasonable default or ask).

    1. On paper, write out the full trace: every Thought, Action (with arguments), and Observation, ending in a Final answer.
    2. Identify at least one point where the agent could take a shortcut (fewer tool calls) without losing correctness.
    3. Identify one point where ReAct's step-by-step nature helps compared to a rigid upfront plan (e.g. if a week number turns out invalid).

    Compare traces across groups — there is more than one valid tool-call order.

    Activity 4 · Individual Lab: Add a Tool, Both Ways

    75 minIndividualGraded (activities)
    • Add a third tool of your choice (e.g. list_free_tier_models() -> list[str], or something relevant to your Corte 2 project idea) to both the ADK agent and the LangGraph agent.
    • Write 3 test prompts that require the model to chain at least two tool calls to answer.
    • In a short NOTES.md, note one behavioral difference you observed between the ADK trace view and the LangGraph console output for the same prompt.
    • Commit your finished apps under week-06/ in your course GitHub repository.

    Activity 6 · Corte 2 Project: Pick Your Problem

    15 minIndividual

    Your Corte 2 deliverable (due Week 11) is a multi-agent system built with Google ADK or LangGraph that solves a real problem and integrates RAG. You do not need a final design today — but write down, in one paragraph, a candidate problem and at least two distinct "roles" it would need (e.g. a researcher agent and a writer agent; a triage agent and specialists). You will refine this as multi-agent patterns are covered in Week 8.
