    Corte 2 · Week 9 of 16

    Lab & Activities

    Quiz, live-coding a routing StateGraph with a checkpointer, sketching your Corte 2 project as a graph, an individual node-building lab, and peer review.

    How this session runs

    2 hours of theory (content page) + 4 hours of hands-on lab (this page). Today you build a real routing StateGraph with a checkpointer, and compare it head-to-head with Week 8's ADK orchestrator.

    Activity 1 · Warm-up Concept Quiz

    10 minIndividualFormative

    1. What does a LangGraph node return?

    Correct answer: A. LangGraph merges the returned partial dict into the shared state.

    2. What must a routing function passed to add_conditional_edges return?

    Correct answer: C. The routing function's return value selects which registered node runs next.

    3. Two separate graph.invoke() calls use the same thread_id and a checkpointer. What happens?

    Correct answer: B. That is exactly what a checkpointer + thread_id gives you: resumable state.

    4. What is the main practical difference between ADK's sub_agents routing and a LangGraph conditional edge?

    Correct answer: A. Explicit graphs make control flow testable code; ADK's LLM-driven routing does not.

    Activity 2 · Instructor-Led Live Coding

    40 minWhole group

    Run agents/week-09-langgraph-i/langgraph/app.py. Send two questions in the same session, then call graph.get_state(config) (already wired into the CLI's /state command) to show the persisted history. Then run agents/week-09-langgraph-i/adk/'s workflow-agent version and discuss: which one was easier to test without an LLM call at all?

    Activity 3 · Group Workshop: Draw Your Corte 2 Graph

    35 minGroups of 3–4

    If your Corte 2 project used LangGraph instead of ADK, sketch it as a StateGraph:

    1. Define the state fields you would need (be specific about types).
    2. Draw each node as a box, and mark which edges are fixed vs. conditional.
    3. Identify what a checkpointer's thread_id would represent in your app (one user? one conversation? one task run?).

    Activity 4 · Individual Lab: Add a Node

    75 minIndividualGraded (activities)
    • Add a fourth route/node to app.py (e.g. a "clarify_node" reached when the classify step is unsure), including its routing-function branch.
    • Write a unit test (plain assert, no LLM call) for your routing function covering all branches.
    • Confirm state persists correctly across two invoke() calls with the same thread_id, and resets with a new one.
    • Commit your finished graph under week-09/ in your course GitHub repository.
