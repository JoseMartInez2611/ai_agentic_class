    Corte 1 · Week 1 of 16

    Lab & Activities

    Quiz, guided coding, a group workshop, an individual lab, peer review, and your first Corte 1 project checkpoint.

    How this session runs

    Each week pairs 2 hours of theory (the content page) with 4 hours of hands-on lab (this page). Lab time mixes instructor-led live coding, small-group workshops, individual work in the notebook, and peer code review, following the course's teaching strategy of active participation and learning by building. Labs are delivered through the course GitHub repository; Moodle carries supporting material and announcements.

    How this counts toward your grade

    Corte 1 (Weeks 1–5) is worth 30% of the course: 25% practical project (a RAG-powered conversational assistant, delivered Week 5) + 5% in-class activities (quizzes, workshops, and labs like the ones below, across all five weeks). Nothing today is worth points in isolation — show up, do the work, and keep your notebook and repo in a state you'd be comfortable showing a reviewer.

    Activity 1 · Warm-up Concept Quiz

    10 minIndividualFormative

    Answer from memory before checking — this is about surfacing what stuck from the theory block, not scoring.

    1. What is a large language model fundamentally doing when it generates text?

    Correct answer: B. Every visible capability (answering, coding, chatting) emerges from repeating next-token prediction.

    2. As a rough rule of thumb, one token of English text is about how many characters?

    Correct answer: C. 1 token ≈ 4 characters ≈ 0.75 words for English.

    3. You're building a function that extracts a date from an email. Which setting best fits that task?

    Correct answer: A. Extraction has one right answer; low temperature keeps output deterministic and repeatable.

    4. What does top_p = 0.9 (nucleus sampling) do?

    Correct answer: B. It's a probability-mass cutoff, not a fixed count.

    5. What does self-attention let a Transformer do?

    Correct answer: C. This is the mechanism behind resolving references like "it" to the right noun.

    Activity 2 · Instructor-Led Live Coding

    45 minWhole group

    Follow along in week-01-llm-fundamentals.ipynb, sections 1–3:

    1. Confirm your .env and API key work with a single test call.
    2. Run the temperature/top-p/top-k sweep together; each student calls out what they observe changing.
    3. Run count_tokens on a few sentences of different lengths and compare against the "1 token ≈ 4 characters" rule of thumb.

    Case-in-point discussion: the instructor will show a real production incident caused by an unexpectedly high temperature default in a data-extraction pipeline — a preview of why these knobs are an engineering decision, not just a creativity dial.

    Activity 3 · Group Workshop: Prompt & Parameter Detective

    45 minGroups of 3–4

    Your instructor will hand each group three model outputs generated from the same prompt at three different, undisclosed temperature/top_p settings.

    1. As a group, rank the three outputs from most to least deterministic-looking.
    2. For each, write one sentence justifying your guess using vocabulary from today's lesson (sampling, distribution, nucleus, peaked/flat).
    3. Propose which setting you'd actually ship for: (a) a support-ticket categorizer, (b) a creative story generator, (c) a JSON-producing data-extraction endpoint.
    4. One member reports back the group's reasoning to the class (2 minutes).

    This is a peer-participation activity that counts toward your Corte 1 class-activities grade.

    Activity 4 · Individual Lab: Complete the Notebook

    90 minIndividualGraded (activities)

    Work through sections 4–5 of the notebook on your own:

    • Reproduce the same call using the raw SDK, a minimal ADK agent, and a LangChain chat model.
    • Complete the two TODO exercises: (1) build your own parameter sweep over a prompt of your choice, (2) write a short function that estimates token count for a string without calling the API, then compare it against the real count_tokens result.
    • Commit your finished notebook to your personal course GitHub repository under week-01/.

    Activity 5 · Peer Code Review

    20 minPairs

    Swap notebooks with a partner and check off each item honestly. Leave inline comments for anything unchecked.

    Activity 6 · Corte 1 Project Checkpoint & Independent Work

    HomeworkIndividual

    Remember the Corte 1 deliverable due Week 5: a conversational assistant that combines context engineering and RAG over a set of documents of your choice, using the Gemini API and ChromaDB, submitted as a GitHub repo (code + README) with a 10-minute live demo.

    This week, before the next class:

    • Choose the document domain your assistant will answer questions about (e.g. your program's course catalog, a hobby's rulebook, your own class notes, a product's documentation). Pick something you have 5–20 real documents or pages for — you'll need it for chunking in Week 4.
    • Write a 3–5 sentence project proposal (what it answers questions about, who it's for) and push it as PROPOSAL.md to your course GitHub repository.
    • Independent reading: skim the Gemini API docs' "Text generation" and "Long context" pages (ai.google.dev) so parameter names look familiar next week.
    • Optional: keep exploring agy (Antigravity CLI) on a personal script — try asking it to add error handling to something you wrote.
